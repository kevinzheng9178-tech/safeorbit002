# Agent 运行安全基线

> 来源：SafeOrbit 内部审计基线

## 工具权限最小化

Agent 默认不应具备删除、转账、发送邮件、修改权限等写操作能力。确需开放时应限定作用范围、设置单次与每日额度，并要求二次确认。所有写操作必须可追溯到具体调用参数。

## 危险动作前置审批

删除数据、批量导出、对外发送、权限变更、资金操作属于危险动作。危险动作应由系统生成处置提案，交由具备审批权限的人员确认后执行，禁止由模型自行决定。

## 敏感数据不出边界

手机号、身份证号、银行卡号、密钥、内网地址不得出现在模型输出与外部工具参数中。对外调用需经域名白名单校验，非白名单地址一律阻断并记录。

## 提示注入防御

检索文档、网页内容、工具返回值均视为不可信输入。模型不应因文档内出现的指令而改变既定流程。发现要求忽略既有指令、索取系统提示、跳过审批的文本，应标记为高风险并留存证据。

## 成本与配额上限

单个任务应设置成本与 token 上限，超出后拒绝后续调用并生成告警。避免无界消耗与死循环。

## 全链路留痕

记录模型调用、工具调用、检索命中、人工介入的完整链路，保留模型名称、版本、提示词版本、检索片段与原始输出。轨迹需支持回放，用于事后复现与责任认定。

## 结论可复核

任何自动化结论都应保留证据引用。规则命中的结论需指向具体步骤；模型给出的判断需标注为建议复核，并附原文摘录；无法定位证据的结论不得作为处置依据。
